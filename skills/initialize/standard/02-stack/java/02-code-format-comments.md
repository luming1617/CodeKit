## 二、代码格式与注释规范

### 【强制】采用 4 个空格缩进，禁止使用 Tab 字符

IDEA 设置请勿勾选 Use tab character；Eclipse 必须勾选 insert spaces for tabs。

### 【强制】大括号与空格的固定写法

- 空代码块简洁写成 `{}`；非空代码块：左大括号前不换行、左大括号后换行、右大括号前换行、右大括号后有 else 则不换行，终止的右大括号后必须换行。
- `if/for/while/switch/do` 等保留字与括号之间必须加空格；二目、三目运算符左右各加一个空格；左小括号与右边相邻字符之间不出现空格。
- 强制转换时右括号与值之间不加空格：`int second = (int)first + 2;`
- 方法参数逗号后必须加空格：`method(args1, args2, args3);`

### 【强制】单行字符数不超过 120，超出换行遵循：第二行相对首行缩进 4 空格，运算符与点号和下文一起换行，多参数在逗号后换行，禁止在括号前换行

### 【强制】IDE 的 text file encoding 为 UTF-8，文件换行符使用 Unix 格式

### 【推荐】单个方法总行数不超过 80 行；不同逻辑、不同语义、不同业务的代码间插入一个空行分隔

没有必要增加若干空格使赋值等号对齐。

### 【强制】类、类属性、类方法的注释必须使用 Javadoc 规范（`/** 内容 */`），不得使用 `// xxx` 方式

### 【强制】所有抽象方法（含接口方法）必须用 Javadoc 注释，除返回值、参数、异常说明外，还必须指出该方法做什么、实现什么功能

### 【强制】所有类必须添加创建者和创建日期

正例：`@author yangguanbao` + `@date 2016/10/31`（日期统一 yyyy/MM/dd 格式）。

### 【强制】方法内部单行注释在被注释语句上方另起一行用 //；多行注释用 /* */；注释的双斜线与内容之间有且仅有一个空格

### 【强制】所有枚举类型字段必须要有注释，说明每个数据项的用途

### 【推荐】代码修改的同时，注释（尤其参数、返回值、异常、核心逻辑）也要同步修改；与其半吊子英文注释，不如用中文说清楚，专有名词保持英文原文

### 【参考】特殊注释标记 TODO / FIXME 需注明标记人、标记时间、预计处理时间，并经常清理

TODO 只能应用于类、接口和方法；线上故障有时就来源于这些标记处的代码。
