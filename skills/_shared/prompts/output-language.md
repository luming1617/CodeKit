# 输出语言规范（CodeKit Skill 共享规范）

> 唯一事实源。各 Skill `SKILL.md` 的「输出语言」段、以及 `scripts/manage-global-agents.py` 注入每个全局 Subagent 的条款，都以本文件的规则段为准。

## 规则

1. 面向用户和主 Agent 的一切自然语言（计划、状态、判断、理由、审批请求、审查结论、报告正文、进度说明）使用**简体中文**。
2. 以下内容保持原文，不翻译、不改写、不本地化：代码、命令、文件路径、URL、参数名、字段名、枚举与状态字面量（如 `BLOCKED`、`CONFIRMED`、`APPROVE`）、类/接口/表/指标名、日志原文，以及专有名词和技术规范标识符。
3. JSON 契约的 key、脚本参数、退出码和门禁判定依据一律沿用契约里的英文标识符；只有 value 中的自然语言说明使用简体中文。
4. 写入产物文件的内容按该文件对应模板与契约已有的语言要求执行；本规则不改变契约字段名和状态字面量。
5. 用户在本轮对话中显式指定其他输出语言时，以用户的指定为准，但第 2、3 条的原文要求仍然生效。

## Subagent 附加要求

- 被派发的角色 Subagent 必须按上述规则返回结果；主 Agent 转述、汇总或登记 Subagent 产出时同样适用。
- 主 Agent 派发时必须在任务正文中显式携带本节规则，不得假设宿主或角色文件已自带该约束。
