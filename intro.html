01 · Overview

不是又一个 Copilot，
而是完整的研发主体。

CodeKit 把团队研发规范、工程方法论、工具链封装成 AI 能直接执行的 slash 命令。 开发者只需按阶段调用技能：读 PRD、写方案、生成发布方案、并行编码和多维 CR。

“规范 + 技能 + 工具链” 三件套让 AI 具备团队工程素养。
它不再需要你手把手教 — 读需求、写方案、跑测试、完成审查，都由它自己完成。

03 · Installation

一条命令，全量装机。

CodeKit 的一键脚本会自动处理 Claude、glab、lark-cli、infra-cli、JumpServer 配置以及双平台插件挂载 —— 你只需要准备好以下前置依赖。

✓
Node.js ≥ 20运行 Claude / OpenCode 的基础环境
node --version
✓
Python 3脚本 & 工具链依赖
python3 --version
✓
Git ≥ 2.50工作树管理与 SCM 操作
git --version
✓
SSH Key访问 git.daming.co 私有仓库
ssh -T git@...
提示： 安装完成后脚本会打印完整的配置步骤。如果 OpenCode 未被自动检测， 可以将 codekit@git+https://git.daming.co/share/CodeKit/marketplace.git 手动添加至 ~/.config/opencode/opencode.json 的 plugin 数组。
INSTALL · UPGRADE · UNINSTALL 
# ─────── 一键安装 ───────
$ curl -sSL https://git.daming.co/share/CodeKit/marketplace/-/raw/main/install.sh \
    | bash -s -- install

# ─────── 升级所有组件 ───────
$ curl -sSL https://git.daming.co/share/CodeKit/marketplace/-/raw/main/install.sh \
    | bash -s -- upgrade

# ─────── 卸载 ───────
$ curl -sSL https://git.daming.co/share/CodeKit/marketplace/-/raw/main/install.sh \
    | bash -s -- uninstall

03.b · Authentication

4 个认证，全平台打通。

STEP 1
SCM

GitLab CLI

在 GitLab Web 创建 Personal Access Token，勾选 api / read_user / read_repository。

glab auth login \ --hostname git.daming.co \ --token <your-token>
STEP 2
DOC · MEEGLE

飞书 CLI

先申请 S10-Lark 自建应用（需审批），审批通过后一键授权。

lark-cli auth base
STEP 3
REMOTE ACCESS

JumpServer

将本机 SSH 公钥添加至 JumpServer。首次跳转需输入谷歌验证码（2FA）。

cat ~/.ssh/id_ed25519.pub # 粘贴到 JumpServer → SSH Key 管理
STEP 4
INFRA

infra-cli

基建 CLI 登录，用于环境信息采集、部署状态查询等。

infra-cli auth login
04 · Workflow

两条主线，覆盖日常。

CodeKit 把研发日常切成两条主链路：需求开发 与 问题排查。每一步都是一条 slash 命令，组合即流程。

W/01

需求开发 · PRD → Code

01
/codekit:product-doc输入

整理并审查产品需求文档，生成 feature-directory。

02
/codekit:technical-doc必选

仅基于 PRD 生成后端技术方案。

03
/codekit:release-doc必选

强校验 PRD + TDD，生成发布方案。

04
/codekit:code-impl必选

创建功能分支并多 Agent TDD 开发。

05
/codekit:code-review必选

对实现进行证据驱动的独立代码审查。

PIPELINE · LINEAR VIEW
product-doc
  └▶ technical-doc
       └▶ release-doc
            └▶ code-impl
                 └▶ code-review ✓
必选 可选 并行
W/02

问题排查 · 6 Phase RCA

/codekit:bugfix [<feature-directory>] <问题描述> —— AI 会跨越业务日志、进程状态、中间件指标、源代码等多个证据源自行找路，严格遵循 6 阶段流程，≥2 个独立源交叉验证假设。

01
明确问题

收敛症状、复现路径、影响范围

02
多源取证

业务日志 / dmesg / 源码 / 指标

03
模式分析

异常时序、依赖链、调用图

04
关联假设

≥2 独立源交叉验证

05
验证假设

通过实验、复现或代码走读

06
修复确认

补丁、回归、守护机制

05 · Command Reference

7 个技能，各司其职。

按需调用、彼此可组合 —— 所有命令在 Claude 和 OpenCode 上用法完全一致。

CATEGORY COMMAND DESCRIPTION
INIT/codekit:initialize强制调用 GitNexus、Graphify、Context Scanner 三个 Subagent，挂载规范并生成 AGENTS.md / CLAUDE.md。
REQUIREMENT/codekit:product-doc整理并审查产品需求文档。
PROPOSAL/codekit:technical-doc仅基于 PRD 生成后端技术方案。
RELEASE/codekit:release-doc基于 PRD + TDD 生成后端发布方案。
CODING/codekit:code-impl多 Agent 按任务图并行 TDD 开发。
REVIEW/codekit:code-review架构 / 安全 / 性能 / 规范 / 测试 —— 5 维度并行 CR。
INIT/codekit:initialize强制调用三路 Subagent，初始化仓库 AI 开发环境。
RCA/codekit:bugfix基于 PRD/TDD/RPD 系统化排查并修复问题。
故障速查： 插件 plugin add 失败 → 检查 SSH Key； 命令不生效（OpenCode） → 检查 ~/.config/opencode/opencode.json 并重启； 安装日志查看 → cat ~/.local/state/CodeKit/install.log。
